# نظام حياتي (Life OS)

تطبيق شخصي بصفحة HTML واحدة، عربي RTL، بثيم داكن (تيل / نعناعي / عنبري)، بينظم يومك في 6 تبويبات:

- **الرئيسية** — ملخص يومك في شاشة واحدة
- **الشغل والنوبات** — نوبات 24 ساعة بالمستشفى، كاليندر من نوفمبر 2026، حاسبة الراحة والدخل
- **المذاكرة والتطور المهني** — مواضيع، جلسات، أهداف
- **الفلوس** — دخل، مصروفات، مدخرات، ورأس مال (شهادة البنك / مدخرات فوري / ذهب / استثمار) مرتبط بالمدخرات
- **الصحة** — سعرات، صيام، وزن، عادات، عيلة، قراءة
- **الإحصائيات** — رسوم بيانية أسبوعية وشهرية

## البناء

الكود متقسم عشان يترفع بسهولة:

```
src/template.html   هيكل الصفحة
src/style.css       التصميم
src/app-1.js        الجزء الأول من الكود
src/app-2.js        الجزء الثاني من الكود
build.py            بيجمعهم
```

```bash
python3 build.py
# الناتج: dist/life-os.html  (افتحه في أي متصفح)
```

## الخصوصية

المستودع فيه الكود بس — **مفيش أي بيانات شخصية**. البيانات بتتخزن في متصفحك (localStorage) أو في نسختك الاحتياطية الخاصة.
